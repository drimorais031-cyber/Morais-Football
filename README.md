# Morais Football ⚽

Protótipo inicial de um jogo de futebol 2D, pensado para navegador de celular e computador.

## Como jogar
1. Publique o repositório com GitHub Pages (Settings → Pages → Deploy from a branch → main → /(root)).
2. Abra o endereço publicado no navegador.
3. Escolha os times e inicie a partida.
4. No computador, mova o jogador com WASD ou setas.
5. No celular, use o direcional na tela. PASSE e CHUTE executam ações quando a bola está próxima.

## Estado do projeto
Versão 0.1: menu, seleção básica de equipes, campo 2D, placar, cronômetro, movimentação e ações iniciais. É uma base de protótipo, não um simulador completo ainda.
